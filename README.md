# EduOffline · Releases / Versiones

**English** · [Español](#español)

Installers for [EduOffline](https://eduoffline.com), the classroom platform that works without internet. This repository only holds the installers: it contains no source code.

**Download:** [latest version](https://github.com/luisaguirred/EduOffline-releases/releases/latest) · [every version and its changes](https://eduoffline.com/versiones.html)

| System | File |
|---|---|
| Windows 10 and 11 (64-bit) | `EduOffline-Setup-X.Y.Z.exe` |
| macOS with Apple chip (M1 or newer) | `EduOffline-X.Y.Z-mac-arm64.dmg` |
| macOS with Intel processor | `EduOffline-X.Y.Z-mac-x64.dmg` |
| Linux, any distribution | `EduOffline-X.Y.Z-linux-x86_64.AppImage` |
| Ubuntu, Debian, Mint | `EduOffline-X.Y.Z-linux-amd64.deb` |

Files ending in `.blockmap` and `latest*.yml` are used by automatic updates; you don't need to download them.

### Installing

- **Windows:** run the `.exe`. If Windows shows "Windows protected your PC", choose *More info → Run anyway*.
- **macOS:** open the `.dmg` and drag EduOffline to *Applications*. The first time, open it with *right-click → Open* (on macOS 15: *System Settings → Privacy & Security → Open Anyway*), and allow incoming connections so your students can join.
- **Linux:** install the `.deb`, or make the `.AppImage` executable (*Properties → Allow executing as program*) and open it. On GNOME, the tray icon needs the *AppIndicator* extension (Ubuntu already includes it).

EduOffline then sits as an icon next to the clock (address and QR code for your students, devices connected, backup, updates) and starts with your computer. Your data stays on your computer: updating or uninstalling doesn't delete it. The setup guide is at [eduoffline.com](https://eduoffline.com/#instalacion).

## Español

Instaladores de [EduOffline](https://eduoffline.com/es/), la plataforma escolar que funciona sin internet. Este repositorio solo guarda los instaladores: no contiene código.

**Descarga:** [versión más reciente](https://github.com/luisaguirred/EduOffline-releases/releases/latest) · [todas las versiones y sus cambios](https://eduoffline.com/es/versiones.html)

| Sistema | Archivo |
|---|---|
| Windows 10 y 11 (64 bits) | `EduOffline-Setup-X.Y.Z.exe` |
| macOS con chip Apple (M1 o posterior) | `EduOffline-X.Y.Z-mac-arm64.dmg` |
| macOS con procesador Intel | `EduOffline-X.Y.Z-mac-x64.dmg` |
| Linux, cualquier distribución | `EduOffline-X.Y.Z-linux-x86_64.AppImage` |
| Ubuntu, Debian, Mint | `EduOffline-X.Y.Z-linux-amd64.deb` |

Los archivos `.blockmap` y `latest*.yml` los usan las actualizaciones automáticas; no hace falta descargarlos.

### Instalar

- **Windows:** ejecuta el `.exe`. Si aparece "Windows protegió su PC", elige *Más información → Ejecutar de todas formas*.
- **macOS:** abre el `.dmg` y arrastra EduOffline a *Aplicaciones*. La primera vez, ábrelo con *clic derecho → Abrir* (en macOS 15: *Ajustes del Sistema → Privacidad y seguridad → Abrir de todos modos*) y permite las conexiones entrantes para que entren tus alumnos.
- **Linux:** instala el `.deb`, o dale permiso de ejecución al `.AppImage` (*Propiedades → Permitir ejecutar como programa*) y ábrelo. En GNOME, el ícono de la barra necesita la extensión *AppIndicator* (Ubuntu ya la trae).

Después, EduOffline queda como ícono junto al reloj (dirección y código QR para tus alumnos, dispositivos conectados, copia de seguridad, actualizaciones) y arranca con la computadora. Tus datos se quedan en tu computadora: actualizar o desinstalar no los borra. La guía de instalación está en [eduoffline.com/es](https://eduoffline.com/es/#instalacion).
